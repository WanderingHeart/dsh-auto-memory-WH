# ADR 0002：S03 离线维护与作用域事务

日期：2026-11-03。状态：采用，开发预览。

选择整个 WH 根写锁加作用域索引锁，使普通修改与离线一致性备份协调；作用域内保存原活动 Markdown 字节作为恢复日志。索引与记录一起提交，prepared 状态回退，committed 状态只清理日志。未知恢复状态阻断读写，Prompt 暂时省略该段。

代价是每次修改复制该作用域的文件集，随规模增加产生明显 I/O；当前通过文件数和字节限额约束，不声称达到最终大规模性能目标。后续可在保持恢复测试的条件下改为增量日志。

删除采用原字节归档，批量删除/修剪额外保留可恢复的作用域快照。快照、归档不自动过期，避免误删唯一恢复点；保留策略和永久隐私擦除属于后续明确功能。

迁移采用独立目标，要求已审查计划哈希、停写确认、源清单重查、一致性备份、逐字节恢复演练和 staging 验证。不自动修改 DSH 配置；完整安装和切换需要后续集成验收。

放弃上游自动清理疑似孤儿锁的行为。进程探测的 EPERM 不证明进程死亡，抢锁者自动删除旧锁也可能与其他抢锁者竞争。当前只提供离线、检查哈希与 PID 后的显式锁释放，并要求操作者停止所有写入者。

沿用旧项目 slug 以保持格式，但新增完整路径绑定；碰撞明确报错。未标记旧库不自动升级。迁移保留原始正文和 frontmatter，不根据猜测补信任状态；非法状态或未知版本列为阻塞项。

S03 版本记为 0.1.0-alpha.0。合成存储验收与完整 G2/G3 分开记录，真实数据和宿主流程尚未验证时不宣布这些门槛通过。
