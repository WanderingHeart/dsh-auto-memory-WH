# ADR 0001：独立身份与数据默认隔离

日期：2026-11-03（Asia/Shanghai）。状态：S02 已采用，后续阶段可通过新的 ADR 修订。

项目沿用用户指定的显示名 dsh-auto-memory-WH；技术包名使用 dsh-auto-memory-wh。插件/面板 auto-memory-wh、API /api/auto-memory-wh、词典 autoMemoryWH、Prompt memory-wh:index、样式前缀 dam-wh- 分别独立。公共工具名维持 memory_*，并检测已有占用。

默认数据根由总规格候选的共享 memory 根改为独立 memory-wh 根。理由是迁移保护尚未完成，默认共用会使开发版意外访问旧数据。可读格式兼容与实时共用目录是两回事；真正导入旧库仍需 S03。此阶段没有移动或读取旧记忆。

核心 DSH peer 声明用 0.1.5-rc.2 || 0.2.1-rc.5，显式接纳两个核心测试基线的预发布版本。没有扩大到任意未来版本。旧版本锁文件用于可复现回归，桌面版本通过独立探针验证；客户端 devDependency 类型基线暂未升级。安装器和真实 UI 未测，因此不宣称这两个完整产品版本均已兼容。

私有开发包和停用自动发布是开发期配置。公开发布前再确定作者署名、正式仓库、包所有权与发布流程。保留上游完整许可证，不冒领原作者贡献。
