# S05 rc.2 跨进程压缩会话持久恢复（r21）

日期：2026-11-03。状态：**partial**。本轮新增隔离验证探针，没有修改 WH 生产代码、已安装 rc.2 包或日常 DSH 配置。

## 验证方法

在**两个独立 Electron Node 进程**中使用本机打包的 DSH `dsh-compaction-basic`、`dsh-session-persistence-jsonl`、`SessionStore`、SystemPrompt、Tools、Loader 及 `wh-s05` 中已安装的 rc.2 bundle。所有会话日志和记忆文件都在项目 `.work/S05` 的新合成目录。压缩进程只注册进程内假模型和计量服务、合成维护 agent；移除常见密钥环境变量并阻断 `fetch`、HTTP(S)、TCP、TLS、UDP 出口。写入进程的假模型调用 **1 次**，两进程网络拦截计数均为 **0**。[写入进程结果](../attachments/public-validation.md)、[读取进程结果](../attachments/public-validation.md)。

## 已通过

1. 写入进程在真实会话对象上完成基础压缩；WH 在压缩前后均注入同一条已审核的合成项目记忆。
2. 通过真实 JSONL 后端的写句柄追加并 flush 压缩后的 **14 条**会话事件，关闭写句柄。
3. 第二进程用同一后端的读句柄重新打开磁盘日志，构造新的 `SessionStore` 会话；压缩开始、摘要、结束事件及替换后的消息表面仍可见，被压缩的旧消息不再出现在派生消息中。
4. 第二进程加载同一已安装 WH bundle，重新从当前记忆源文件注入已审核记录。关闭后核对审计共 **3 条**：写入进程压缩前后两条、读取进程一条，均为非零片段且含该记录。

这比 r17 的纯内存快照种子更接近真实恢复：会话事件确实经宿主 JSONL 后端落盘，并由另一个进程读取。已安装 bundle SHA-256 为 `b0c01b90575d7e5e0efe6fd6dc6f0cb71003463ca4db8818450c52c3164ad04a`。
