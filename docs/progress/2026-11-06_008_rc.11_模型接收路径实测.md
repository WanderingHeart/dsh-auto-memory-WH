## 方法

1. 在**日常 DSH home** 新建测试 profile `wh-model-test`（`--from-default-profile headless`，仅用于本次测试；结束删除）：  
   `dsh --profile wh-model-test --dump-config` 显示 headless 默认 `agent-default-model = deepseek-official/deepseek-flash`，而 `credentials`/`authorization`/`deepseek-account` 在 headless 模板中默认关闭。
2. 用 overlay patch `.work/S05/model-receipt-home/account.yml` 打开 `credentials`、`authorization`、`deepseek-account`，并把默认模型切到 `provider: deepseek-account, model: deepseek-flash`。先验证：`dsh --profile wh-model-test --patch … headless "Reply with exactly OK"` → 输出 `OK`，stderr 出现 `[llm-deepseek-account] model listing from https://api.deepseek.com/models loaded 2 model(s)`，证明走的是真实账号路由。
3. 安装候选包到该 profile（绝对路径；pnpm 把相对路径解析到 `%USERPROFILE%\.dsh\profiles\wh-model-test`，会报 ENOENT）：  
   `dsh plugin --profile wh-model-test add <abs>\.work\dsh-auto-memory-wh-0.1.0-rc.11.tgz --ignore-scripts --prefer-offline --store-dir <abs>\.work\S05\model-receipt-home\pnpm-store`。

5. 单轮 headless 调用（prompt 明确“不调用工具，只依据系统提示中的记忆索引逐条复述名称与摘要，索引为空则回答 EMPTY”），抓完整 stdout/stderr/exit 到 `model-run.json`，并读取合成根 `audit.jsonl`。
