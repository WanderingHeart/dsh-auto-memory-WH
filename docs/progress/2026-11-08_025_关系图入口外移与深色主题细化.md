# v0.10.1 关系图入口外移与深色主题细化

## 1. 输入

所有者（2026-11-08）：

1. 关系图“从设置里移到外面来”，与“新建 / 未审核 / 重复与合并 / 筛选”并列；
2. “顺便做深色主题细化”。

## 2. 改动

### 2.1 工具栏入口

- `src/client/ManagementPage.tsx`：工具栏在“筛选”之前新增“关系图”按钮；点击时打开图视图，同时清掉编辑器草稿与合并面板，避免三层浮层叠在一起。
- 设置菜单里原来的“关系图”入口删除，菜单恢复为九项。
- 关系图返回列表用“返回列表”按钮，行为不变。

### 2.2 深色主题细化

`src/client/index.ts` 的 `@media (prefers-color-scheme: dark)` 块扩展为：

- 根背景：`color-mix(bg-base 96%, #000 4%)`，卡片、合并区、画布统一 `bg-layer-1` 加半透明边框；
- 设置菜单、抽屉、筛选弹层使用更深阴影，与页面层次拉开；
- 进度条改蓝紫渐变（`#6f9bff → #8fb2ff`），在深色底上更清楚；
- 次要文字 88% 不透明度，编辑器输入与按钮使用深色底与边框，hover 提亮。

### 2.3 测试与一个性能修复

- 面板测试补断言：`关系图` 按钮必须位于工具栏内（防止再被挪回设置）。
- 首次隔离验收在 `unit` 步失败：`tests/graph.spec.ts` 的“500 条记录构图”耗时 2,233 ms，超过 2,000 ms 预算（真实负载 + 55 个测试文件并行时更慢）。
- 根因：`buildGraph` 对每条记录调用 `rankRelated`，同一段正文被反复分词（500 条 → 约 25 万次）。修复：`src/relatedness.ts` 的 `tokenize` 增加词元缓存（上限 4,096 条，超出整体清空）。
- 修复后同一用例 495 ms；全量 48 文件 / 509 用例通过。

## 4. 边界

- 深色主题只调了“层级与对比度”，没有重做配色体系；如果仍有某处对比度不足，按具体位置再调。
- 关系图参数（旋转速度、缩放范围、节点间距）仍是固定值，没有做用户可调。
- 桌面需要完全重启后才会加载 0.10.1 的前端 bundle。
