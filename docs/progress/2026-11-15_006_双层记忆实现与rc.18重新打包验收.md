日期：2026-11-15。版本：1.0.0-rc.18。状态：本地候选准备完成，未正式发布、未推送 GitHub、未调用 npm publish。

## 行为

- user / feedback / project / reference 四种类型都适用于两个作用域。
- 自动/手动会话总结在原有一次模型请求中生成项目级详情和 userSummary；有效短概括自动保存为同类型的用户级普通记录。
- memory_write 同样支持 userSummary，主记录成功后自动保存用户概括。
- 来源按项目 cwd 和来源身份关联；重复总结更新同一概括，矛盾取代沿原来源链维护。固化匹配限制同作用域，防止项目详情覆盖同名用户记忆。
- 概括不复制详情、证据摘录或项目主题 id；长度最多 160 字符，明显路径/凭据格式拒绝。模型遗漏/输出无效或保存失败时详情仍在，日志或工具结果报告原因。
- 尊重 enableUserScope；自动总结沿用 standard/full 档和 autoSummarize 开关/门槛。没有新开额外模型请求，但模型输出 token 可能增加。每批主记录上限不包含最多每条一条的附加概括。
