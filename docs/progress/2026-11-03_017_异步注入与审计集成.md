# S05 异步注入与审计集成（r12）

日期：2026-11-03。状态：partial。工作树仍标记 0.1.0-rc.0，但原有 rc.0 tgz 不包含本轮修改；未重新安装或发布。

## 改动

正式插件将记忆段同步注册为空文本，并在宿主 `system-prompt/assemble` 异步 waterfall 中调用 scanAsync、生成原有预算格式的段落，然后替换同名记忆段。注入文本的排序、转义、审核筛选和预算仍由原有渲染逻辑处理。同步渲染函数保留给既有直接调用路径；异步路径只在任一启用范围出现 storage-unavailable 时整体返回零字节，防止用户范围已审核记录在项目范围不可读时被当作完整组合注入。

审计现在支持异步组装，保持每次有效组装一次 render_attempt、完整段落字节数和排除原因。异步渲染异常时返回空段并记录 async-render-failed；审计写入本身仍排队，不能等同于模型已经接收。

## 验证
