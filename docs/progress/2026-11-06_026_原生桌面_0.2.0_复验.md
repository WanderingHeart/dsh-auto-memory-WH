## 观察

- 本次动态关闭与 r108 是两种不同的安全结果：
  - r108：保存已在关闭前完成（哈希变化），重启后元数据保持；
  - r123：关闭落在写入中途，journal 回滚、哈希回到关闭前值，重启后记录状态与正文保持。
  - 两者都满足“要么完整提交、要么完整回滚”，没有半截记录、锁或临时文件残留。
- 0.2.0 的 `engines.dsh` 放宽后，原生实例在 DSH `0.2.2-rc.1` 上正常加载，侧栏与输入框可用；宿主没有跳过 bundle。

## 边界

- 仍是合成记忆 + 本机 mock 模型 + 隔离 home；没有触碰真实 `~/.dsh/memory-wh`。
- 0.2.0 新增的客户端按钮（批量审核、查找近重复、立即备份、迁移检查）没有被逐一人工点击；本轮只证明面板能加载、原有保存/注入链路未被破坏。
