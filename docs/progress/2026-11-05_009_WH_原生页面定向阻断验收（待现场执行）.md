## 离线操作

使用普通 PowerShell，不以管理员身份运行。先正常退出所有 DSH，再断开电脑互联网。不要输入 API Key、登录、发送对话、编辑真实记忆。下列命令与之前隔离操作使用同一路径；每条返回预期状态才继续。任何异常先停止页面操作，正常退出 DSH 后仍执行第 5 步卸载；不要自行重试保存。

1. 安装隔离测试包，应返回 `installed-in-isolated-desktop-profile`：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Install -PostRemoveBaseline -OfflineConfirmed
   ```

2. 检查并启动隔离桌面，应依次返回 `ready-for-isolated-wh-desktop-launch`、`isolated-wh-desktop-launched-not-yet-accepted`：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Check
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Launch -OfflineConfirmed
   ```

   如出现欢迎页，选“添加 API Key → 稍后配置”。进入“记忆 WH”→“用户记忆”，打开 `native-ui-synthetic` 的“查看 / 编辑”。只把摘要改为 `阻断预检草稿-r76`，**此时不要保存**。

3. 按 F12 打开开发者工具，进入 Network/网络。确保速度仍是 **No throttling/不限速**。打开 **Request conditions / 请求条件**（旧版可能叫 **Network request blocking / 网络请求阻断**；可用 Ctrl+Shift+P 搜索 `Show Request Blocking`）。添加并启用 URL 模式 `*api/auto-memory-wh/*`，保持开发者工具打开。不要使用 Console，不要刷新整个网页。

   回到 WH 页面，点页面右上角 **“刷新”一次**，观察三件事：Network 中 `groups.list` 请求状态明确为 **`(blocked:devtools)`**；页面出现 WH 的连接失败提示；编辑器和 `阻断预检草稿-r76` 仍在。**缺任何一项就不要点“保存更改”**。关闭请求阻断，正常退出并按第 5 步卸载，恢复网络后告诉我预检结果。

4. **只有第 3 步三项都成立**，才点一次“保存更改”。预期 Network 的 `memory.write` 也标为 `(blocked:devtools)`，页面提示连接中断，编辑器和草稿仍在。若保存反而成功、页面崩溃或草稿消失，立刻停止，不重试、不手工改记录；正常退出并卸载，恢复网络后由我按备份核对/恢复。

   若预期成立，关闭请求阻断，点“放弃草稿并关闭”，再点页面“刷新”，确认原摘要“隔离桌面交互验收-r67”、已审核、已静音。关闭 DevTools 并正常退出 DSH。截图可保留状态，但不要包含 URL 中的本机 token 或 `.work` 原始日志。

5. 确认所有 DSH 窗口和进程已退出，再卸载隔离插件，应返回 `removed-from-isolated-desktop-profile`：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Remove -OfflineConfirmed
   ```

恢复网络后，告诉我四段命令状态、只读刷新是否出现 `(blocked:devtools)`、是否点击过保存、保存后的页面状态。我会再运行隔离文件与卸载核对。**不要仅凭 DSH 左下角“连接异常”判断保存失败；r75 已证明它和 WH 本机写入可同时出现。**

本方案即使通过，也只证明 DevTools 对此原生页面请求的阻断与草稿保留，不代表真实断电、服务崩溃或模型接收路径。v0.1.0 工作量粗估仍约 **85%**。
