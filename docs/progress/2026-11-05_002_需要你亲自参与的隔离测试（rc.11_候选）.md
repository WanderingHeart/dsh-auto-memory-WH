## 测试 A：磁盘写满（15 分钟）

> 状态：**已执行一次（2026-11-05，r96，PASS）**，证据 `docs/evidence/S05-rc11-manual-disk-full/result.json`。若候选包更新，再按本步骤重跑。

目的：验证磁盘真的写不进去时，**不会把已有记忆写坏**，并且空间恢复后能继续保存。

### A1. 准备一个 2 GB 的虚拟磁盘（只需做一次，需要管理员）

1. 按 `Win + X`，选“Windows 终端(管理员)”或“PowerShell(管理员)”。
2. 建一个目录放虚拟磁盘，例如 `C:\vhd`（如果不存在）：
   ```powershell
   New-Item -ItemType Directory -Path C:\vhd -Force
   ```
3. 依次输入下面几行（每行回车一次；这是 Windows 自带的 `diskpart`）：
   ```powershell
   diskpart
   create vdisk file="C:\vhd\wh-disk-full.vhdx" maximum=2048 type=expandable
   select vdisk file="C:\vhd\wh-disk-full.vhdx"
   attach vdisk
   create partition primary
   format fs=ntfs quick label=WHFULL
   assign letter=F
   exit
   ```
4. 打开“此电脑”，应该能看到一个新的 `F:` 盘，标着 `WHFULL`。

4. 你会看到屏幕先刷出一行行 `PASS ...`，中间有一条 `"ok":false` 的 JSON（这是**故意**让写入失败的），最后是：
