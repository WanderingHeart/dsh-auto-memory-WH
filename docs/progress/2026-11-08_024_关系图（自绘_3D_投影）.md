# v0.10.0 关系图（自绘 3D 投影）

## 1. 动机

相关性评分在 v0.7.0 已落地（`relatedness.forRecord`、每条记忆展开区的“相关记忆”），但只能逐条看。所有者希望把记忆之间的关系整体呈现出来，作为后续自动合并评估与三维呈现的底座。

方案比较（v0.9.1 会话内与所有者确认）：

- A：2D 力导向图——简单，但没有“三维呈现”的观感；
- **B：轻量自绘 3D 投影（选定）**——纯 canvas，无第三方依赖，包体与运行开销都可控；
- C：three.js——能力最全，但引入 600KB+ 依赖，与“0.x 每版可回退、预算敏感”的节奏不符。

## 2. 实现

### 2.1 服务端 `relatedness.graph`

- `src/relatedness.ts` 新增 `buildGraph(records, { neighbors = 6, threshold = RELATEDNESS_WEAK })`：对每条记录复用 `rankRelated`，同一对记录只保留高分边，统计 `degree`，返回 `{ nodes, edges, thresholds }`。
- `src/management-api.ts` 新增只读路由 `relatedness.graph`（POST）：scope 校验与 `relatedness.forRecord` 一致；`threshold` 夹在 0–100；候选集为 user scope 加上项目 scope（同 cwd，标记 `sameProject`）。
- 500 条记录内一次构图在测试中低于 2 秒预算，正常真实库（约 20 条）是一次毫秒级调用。

### 2.2 客户端纯计算 `src/client/graph.ts`

- `hashString`（FNV-1a）给节点确定性的初始位置；
- `seedGraph`：按类型分纬度带（user/feedback/reference/project/task），球面分布，刷新不跳；
- `relaxGraph`：一次性力导向（斥力 + 边拉力 + 半径上限），只在打开视图时排版，不参与每帧动画；
- `rotatePoint` / `projectPoint`：绕 Y/X 旋转 + 透视投影，返回屏幕坐标、深度与缩放。

上述函数无 DOM，可直接单测。

### 2.3 面板 `MemoryGraphView`

- 位置：设置菜单 → “关系图”，占满面板内容区；“返回列表”回到原列表。
- 交互：拖拽旋转（纵向 ±1.3 弧度）、滚轮缩放 0.5–2.2、点击节点跳到该条记忆（清空搜索、回到第一页）。
- 视觉：边按相关性分数调透明度/线宽，节点按类型着色、大小随 `degree` 与透视缩放；悬停显示标题。
- 只读：不写文件、不合并、不改审核状态；`prefers-reduced-motion` 时停止自动旋转。

## 4. 边界与未做

- 打开视图时一次性布局，不持续跑物理模拟；节点很多时（>500）会先截断到当前范围。
- 关系图只表示“评分 ≥30 的边”，不做语义聚类；边的意义仍然是共享词、显式引用、同项目与时间邻近。
- 深色主题细化、节点拖拽固定、导出图谱图片均未做。
- 桌面需完全重启后才会加载 0.10.0 的前端 bundle。
