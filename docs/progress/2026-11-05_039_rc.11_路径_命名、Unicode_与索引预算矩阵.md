## 关键观察

- 名称写入要求已经是 canonical 形式（`normalizeName(record.name) === record.name`）：大小写、斜杠、`..`、中文、Windows 设备名、超长名都在写入前被拒绝，不会产生子目录或越界文件；`read('../evil')` 也被归一化后落空，不会读到作用域外。
- 正文/摘要的 Unicode 往返无损，只有解析器会裁掉一个行尾换行；含 `---`、`#`、`name:` 的正文不会破坏 frontmatter。
- 同步扫描是全有或全无的 fail-closed：作用域里出现 `con.md`（`inside()` 的 `safeRelative` 拒绝设备名）时，`scanSync` 返回空记录 + `storage-unavailable`，注入文本为空——不会“部分信任”，但会暂时失去整个作用域的可用性；异步 `scanAsync` 的失败面未在本轮覆盖。
- `list` 在同样条件下仍能返回可读记录（逐文件容错），与 `scanSync` 的差异是既有实现，本轮按现状记录，未改代码。
- 索引预算：pinned 优先，其余按重要性/更新时间/id 排序；预算裁剪与信任排除分别用 `budget` 与 `candidate`/`disabled` 标注，`excluded` 与 `truncated` 可区分“没进预算”和“没通过信任”。

## 边界

- 合成目录与合成记录；未接触真实记忆、模型、DSH 配置或原生窗口。
