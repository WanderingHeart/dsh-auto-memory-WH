# DSH 0.2.2-rc.4 / rc.5 适配与隔离 Host 验收

范围：现有 Draft PR；不合并、不发布、不升级日用 profile、不改存储格式。`engines.dsh` 已涵盖这两版（实际宿主使用 `includePrerelease`），缺的是七项宿主服务的 peer 声明。补齐精确版本，保留旧声明。`agent/created` 回调仍为同步监听，按新接口显式声明 `undefined` 返回类型。新版工具注册表与执行器分离；提示词测试夹具挂载无执行能力的展示适配器。

文件锁仍由 DSH `dsh-atomic-write` 管理。rc.4、rc.5 对符合宿主格式且 PID 探测返回 `ESRCH` 的锁允许自动接管；活 PID、未知格式不自动解锁。旧宿主的停写、指纹比对和人工恢复仍受测。未添加按超时或文件时间直接删锁的逻辑。

## 复现

基线：`npm ci --ignore-scripts` 后运行 `npm run check`。新版：分别运行 `npm run check:dsh -- 0.2.2-rc.4` 和 `npm run check:dsh -- 0.2.2-rc.5`；使用新建的 `.work` 子目录安装并核验宿主版本，保留原工作区依赖与锁文件。应以 `--ignore-scripts` 安装，且不要用 `--force` 或 `--legacy-peer-deps` 掩盖宿主冲突。

Desktop Host：先构建，保持外网受限且允许回环，在仓库根目录执行以下 PowerShell，结果只落在 `.work/desktop-host-*`。这不是原生窗口验收，脚本直接将构建产物放进隔离 profile，不调用外网包管理器；不要提交原始日志或测试目录。

```powershell
$env:ELECTRON_RUN_AS_NODE = '1'
& 'C:\DeepSeek Harness\DeepSeek Harness.exe' --expose-internals scripts/verification/check-desktop-host.cjs
Remove-Item Env:ELECTRON_RUN_AS_NODE
```
