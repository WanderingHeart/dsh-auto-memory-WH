## 2. 改动

### 2.1 工具栏

- “未审核”成为与“新建 / 重复与合并 / 筛选”并列的按钮，同键切换为“未审核：收起”；其它状态筛选从 UI 移除（默认列表仍隐藏 superseded）。
- “新建”在新建草稿打开时变为“新增：取消”，点击完全丢弃草稿（不保留未保存内容）。
- “筛选”弹层只保留类型下拉；启用时摘要显示“· 已启用”；点空白处或 Esc 退出。

### 2.2 键盘

- 统一 Esc：新建 / 未审核 / 筛选 / 重复与合并 / 搜索 / 设置 / 功能面板都可收起。

### 2.3 编辑器与卡片

- 编辑器摘要、正文默认 38px 单行高度，聚焦时展开到 120–320px。
- 卡片摘要单行省略（`.dam-wh-desc`）。
- 移除“静音”按钮与“已静音”文案。

### 2.4 标题

- 页面标题 `.dam-wh-title` 改为 30px/700、行高 1.15、字距 -.03em（方案 C）。
