# r202 — v1.0.0-rc.15 面板导出与归档确认修复

## 目标与范围

- 修复面板“导出 JSON 包”总是报“宿主返回了无法识别的响应”。
- 修复“移至归档”点击后看起来没有反应。
- 不改变服务端协议与数据格式；只改客户端调用方式与确认区位置。

## 实现

- `src/client/ManagementPage.tsx`：`exportPackage()` 的 `request('export.package', target)` 补上 `'POST'`。服务端路由只接受 POST，此前默认 GET 落到 404，宿主返回 HTML。
- `src/client/ManagementPage.tsx`：归档确认从列表底部整块挪到记录行内，点“移至归档”后同一行出现“确认归档 / 取消”，不再需要滚动寻找。
- 测试：新增“downloads the JSON package through a POST request”（断言 method 为 POST、下载名 `wh-user-package.json`）；归档用例继续覆盖“先确认、后调用 `memory.delete`”。
