# v0.12.1 — 工具栏“档位”滑条与运行时切换（r179）

**日期**：2026-11-08
**目标**：把功能档位从“只能改配置”变成面板上可点的入口；按所有者要求，在工具栏与“新建 / 未审核 / 重复与合并 / 关系图 / 筛选”并列，点开是一条低 / 中 / 高滑条。

## 1. 动机

v0.12.0 让 `edition` 影响注入预算与可选功能，但只能改 DSH profile 的 `cordis.patch.yml` 再重启。所有者希望：

- 档位切换在面板里可点，与其它工具按钮并列；
- 点开后是一条可拖动的条：最左低、中间中、最右高；
- 切换后立即看到界面变化，不必为一次试档去改 YAML。

## 2. 实现

### 2.1 设置持久化

新增 `src/settings.ts`，把“面板里选的档位”写到记忆根下的 `settings.json`（`~/.dsh/memory-wh/settings.json`），而不是改 DSH profile：

- `SETTINGS_FILENAME = 'settings.json'`；`PluginSettings = { version: 1; edition?: Edition }`；
- `loadSettings(root)`：坏 JSON、非法 `edition` 一律回退 `{ version: 1 }`，不让一个坏文件拖垮插件；
- `saveSettings(root, patch)`：临时文件 + `rename` 原子替换，权限 `0600`；
- `readEditionOverride` / `saveEditionOverride`：读写面板选择。

优先级：`settings.json` 里的选择 > `cordis.patch.yml` 的 `edition`。这样面板切换立即生效，而配置项仍是默认值。

### 2.2 运行时切换

- `src/index.ts`：`let edition = readEditionOverride(rootDir) ?? config.edition`、`let features = editionFeatures(edition)`；`setEdition(next)` 校验、更新内存、写文件，返回 `{ edition, features }`。
- `registerMemoryTools(..., { enableRemind: () => features.reminders })`：`memory_remind` 的注册与执行都按当前档位判断。
- 自动备份 `tick()` 开头 `if (!features.autoBackup) return`。
- API 配置改为 `edition: () => edition`、`features: () => features`、`setEdition`。
- `src/management-api.ts`：`currentEdition()` / `currentFeatures()` 取代静态值；`EDITION_DISABLED` 提示里带当前档位；新增 `edition.set`（POST，`edition` 字段），非法档位 400 `INVALID_INPUT`，宿主不支持切换时 400 `EDITION_DISABLED`；成功返回 `{ ok: true, edition, features, restartRequired: false }`。

### 2.3 面板

- 工具栏新增“档位”弹出层，内容是一条 `<input type="range" min="1" max="3" step="1" aria-label="功能档位">`，两端标注低 / 中 / 高，下方提示“切换立即对面板与 API 生效；自动总结/自动备份的下一次运行按新档执行。记忆数据不变。”
- 拖动后调用 `edition.set`，随后 `reload()`：被关闭的入口（关系图、重复与合并、导出、迁移、批量审核、立即备份）当轮消失，`memory_remind` 工具面同步变化。
- “档位”弹层与“筛选”弹层同为 `.dam-wh-filter` 结构；为避免 `querySelector` 先命中档位层，档位层排在筛选层之后。
- 外部点击、Esc 关闭；深色模式下弹层与滑条有对应样式。

### 2.4 测试

- `tests/settings.spec.ts` 3 例：默认值、往返、坏文件 / 非法值忽略。
- `tests/editions.spec.ts` 追加 2 例：动态 `edition` / `features` 下 `edition.set` 生效并让 `relatedness.graph` 立刻 403；未知档位 400、无 setter 宿主 400 `EDITION_DISABLED`。
- `tests/management-page.spec.tsx` 追加 1 例：点开“档位”、把滑条拖到 1，发送 `edition.set { edition: 'minimal' }`，刷新后“关系图/重复与合并”消失。

## 4. 边界

- 面板切换写 `settings.json`；删掉该文件即回到配置默认值。
- 自动总结与自动备份在“下一次运行”按新档执行；已经排定的后台任务不会中途取消。
- 老宿主（没有 `setEdition`）返回 `EDITION_DISABLED`，提示“当前插件不支持运行时切换档位”，不会静默失败。
- 三档仍共用同一份 `memory-wh`，切换不改写任何记录，也不改变审核/信任语义。
