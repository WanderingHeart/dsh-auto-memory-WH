请用**普通 PowerShell**，不要以管理员身份运行。先正常退出所有 DSH，再断开电脑互联网。只操作下面的隔离合成记录；不要输入 API Key、登录、发送对话或编辑真实记忆。任何一步与预期不符就停止页面操作，记下现象；能正常退出 DSH 时仍运行第 5 步的隔离卸载，保留测试数据，恢复网络后告诉我。

2. 检查并启动隔离桌面。依次看到 `ready-for-isolated-wh-desktop-launch` 和 `isolated-wh-desktop-launched-not-yet-accepted`，再继续：
