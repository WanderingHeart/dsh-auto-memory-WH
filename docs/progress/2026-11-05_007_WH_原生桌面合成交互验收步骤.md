# WH 原生桌面合成交互验收步骤

日期：2026-11-05。对象：DSH Desktop `0.2.1-rc.5` nightly、WH 本地包 `0.1.0-rc.8`，只使用项目 `.work/S05/native-real-user-home` 的合成记录 `native-ui-synthetic`。**本轮交互已由用户执行，结果见[r68](2026-11-05_013_rc.8_原生桌面合成交互验收.md)。以下保留当时的操作步骤作为复核记录，勿当作需要再次执行的指令。** 原生只读页面的现场结果和卸载后核对见[r66](2026-11-05_011_rc.8_原生桌面合成记录验收.md)。

## 已核对的起点与回退依据

- 正常 Windows 用户的只读安装检查返回 `ready-for-isolated-desktop-reinstall`；WH 目前未安装在隔离桌面 profile，DSH 进程数为 0。固定包、五个 profile 文件与 r65 备份一致。
- 合成记忆根的 `.wh-format.json`、空 `MEMORY.md` 和 `native-ui-synthetic.md` 三个文件已逐个备份到项目 `.work/S05/native-wh-ui-memory-baseline-r67/`，原件与备份 SHA-256 相同。[操作前检查](../attachments/public-validation.md)确认记录是待审核、未置顶、未静音，摘要为“隔离桌面测试记录”。这不是日常记忆备份。
- [事后核对工具](../../scripts/verification/native-wh-interaction-check.mjs)只读检查合成记录的摘要、审核/置顶/静音状态、正文、空索引、无锁/事务日志、WH 卸载状态和 profile/测试凭据指纹。若测试失败，保留现场供诊断，不手工覆盖记忆。

## 用户离线操作

请在普通 PowerShell 窗口执行，不要以管理员身份运行。先正常退出所有 DSH 窗口，然后断开互联网。以下命令只针对项目内隔离 profile；每一步不符合所写状态就停止，恢复网络后把结果告诉我。

1. 安装本地 WH 包：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Install -PostRemoveBaseline -OfflineConfirmed
   ```

   看到 `installed-in-isolated-desktop-profile` 才继续。

2. 检查并启动隔离桌面：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Check
   ```

   看到 `ready-for-isolated-wh-desktop-launch`，再运行：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Launch -OfflineConfirmed
   ```

   看到 `isolated-wh-desktop-launched-not-yet-accepted` 并出现窗口才继续。和上次一样，若停在欢迎页，点击“添加 API Key”再点“稍后配置”；**不要输入密钥或登录**。

3. 在“记忆 WH”的**用户记忆**范围，只操作 `native-ui-synthetic`：

   - 点“查看 / 编辑”，确认正文只是“仅用于隔离桌面验收的合成记忆；不代表用户真实经历或偏好。”；把“摘要”改为 **`隔离桌面交互验收-r67`**，勾选“审核当前内容”，点“保存并审核”。等待页面完成更新，确认卡片显示新摘要和“已审核”。
   - 点这条记录的“置顶”，等待更新并确认出现“置顶”。
   - 点“静音”，等待更新并确认出现“已静音”，记录仍在列表里。点击页面“刷新”，再次确认新摘要、“已审核”、“置顶”、“已静音”都在。

   只操作上述合成记录；不要发送对话、导入旧记忆、导出文件、填写真实资料或密钥。页面报错、按钮状态不符或草稿未保存时停止并保留现场。可截取 DSH 页面画面；不要发送项目 `.work` 下的原始日志，其中可能有临时本机访问令牌。

4. 若页面操作都成功，正常退出 DSH，确认没有 `DeepSeek Harness` 进程后，运行卸载：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Remove -OfflineConfirmed
   ```

   看到 `removed-from-isolated-desktop-profile` 后恢复网络，把四段状态输出、页面现象及截图发我。我会运行只读事后核对，确认记录持久化、索引排除、卸载和原始备份均符合预期。**不要手工恢复或删除合成记录。**

本步骤只验证原生页面的编辑、人工审核、置顶、静音和刷新，以及退出后磁盘状态；不会证明模型实际接收、会话注入审计、并发编辑冲突或断网草稿保护。当前 v0.1.0 工作量估算仍约 **80%**，本轮实际完成后再评估。
