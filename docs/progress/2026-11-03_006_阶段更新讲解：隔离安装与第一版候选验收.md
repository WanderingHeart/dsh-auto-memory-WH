## 3. 改动讲解

- **一次点击一份导出文件：** beta 同时触发两个下载，浏览器只留下 Markdown，JSON 被阻止。rc 增加“导出逐文件清单”独立按钮；实测两个文件分别下载成功，不放宽浏览器下载权限。JSON 含原文和哈希，合并 Markdown 仍不是恢复备份。
- **可理解的认证错误：** 401 提示重新打开页面并先保留草稿；403/非 JSON 错误页及截断 JSON 不再暴露解析异常。服务器的 REVISION_CONFLICT 仍保留，页面不自动覆盖草稿。
- **新增验证工具：** host-contract-inspect.cjs、host-http-probe.cjs、scale-probe.mjs、isolated-cli.ps1、isolated-lifecycle.mjs、export-check.mjs。运行范围均记录到项目隔离目录。
- **版本元数据：** package、锁文件及审计/维护输出同步为 0.1.0-rc.0；WH v1 存储格式不变，未新增运行时依赖。
