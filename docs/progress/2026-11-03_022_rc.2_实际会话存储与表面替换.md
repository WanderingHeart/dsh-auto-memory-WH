## 不能据此宣称的行为

本轮 `replace` 是直接调用会话表面 API 的无模型等价操作，**没有运行 DSH 的压缩命令**；快照种子由内存提供，没有经过持久会话后端的写入、进程重启或磁盘恢复。子会话带有真实 `SessionStore` 元数据，但没有启动子代理工厂或执行模型请求。agent 外壳是测试对象，因此仍不能代表真实 agent loop 的取消、压缩、恢复和子代理调度。T18 获得更具体的宿主接口证据，完整 T18/G4 继续开放。
