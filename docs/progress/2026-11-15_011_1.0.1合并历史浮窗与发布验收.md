# 1.0.1 合并历史浮窗与发布验收

日期：2026-11-15。用户授权更新后同步发布 npm 和 GitHub。

## 变化

- 最近自动合并按时间倒序，只显示三条。
- 标题右侧增加“查看全部合并”，浮窗滚动显示当前范围的自动、手动及历史合并，展开查看合并正文。
- 浮窗支持 ×、点击窗外、Esc 关闭；点窗内不会关闭，Esc 优先关闭历史窗而不收起合并区域。
- 已有自动合并账本中的用户级记录保留撤销入口。旧手动合并根据现存 supersededBy 来源关系还原，只读显示；缺失的历史、原文或撤销依据不会伪造。账本最多100条这一存量限制没有改变；“全部”指当前范围可查到的现存合并，不宣称无限历史。
- 新 merge.history 接口复用范围与档位校验；不返回其他范围的合并正文。
