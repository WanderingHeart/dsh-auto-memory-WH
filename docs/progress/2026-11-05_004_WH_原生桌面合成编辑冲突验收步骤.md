## 用户离线操作

请在**普通 PowerShell** 窗口操作，不要以管理员身份运行。先正常退出所有 DSH 窗口，再断开互联网。每一步不符合预期就停止，保留隔离目录和页面，恢复网络后告诉我；不要反复运行制造冲突命令。

1. 安装本地包，看到 `installed-in-isolated-desktop-profile` 后继续：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Install -PostRemoveBaseline -OfflineConfirmed
   ```

2. 检查，看到 `ready-for-isolated-wh-desktop-launch` 后启动，看到 `isolated-wh-desktop-launched-not-yet-accepted` 且窗口出现后继续：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Check
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Launch -OfflineConfirmed
   ```

   若停在欢迎页，按上轮路径点“添加 API Key → 稍后配置”。不要输入密钥或登录。

3. 在“记忆 WH”的**用户记忆**范围找到 `native-ui-synthetic`。确认显示旧摘要 `隔离桌面交互验收-r67`、已审核、置顶、已静音。点“查看 / 编辑”，**仅在尚未保存的编辑器中**把“摘要”改成 `未保存的冲突草稿-r69`。不要勾选审核，不要点保存，保持编辑器打开。

4. 另开一个普通 PowerShell 窗口，**只运行一次**下面的受控外部更新。必须看到 `"pass":true` 和 `synthetic-revision-bumped`。若失败，先不要在页面点保存：

   ```powershell
   & "C:\Program Files\nodejs\node.exe" "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-wh-conflict-check.mjs" bump
   ```

5. 回到仍打开的编辑器，点“保存更改”。预期出现“内容已变化，未覆盖当前版本。请保留草稿并重新读取。”一类冲突提示，编辑器和 `未保存的冲突草稿-r69` 仍保留。**不要再试图强制保存这个旧草稿。** 观察后点“放弃草稿并关闭”，再点页面“刷新”：记录应仍是旧摘要 `隔离桌面交互验收-r67`、已审核、已静音，但不再置顶。

6. 若上述现象符合，正常退出 DSH，确认没有 `DeepSeek Harness` 进程，再卸载隔离插件：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Remove -OfflineConfirmed
   ```

   看到 `removed-from-isolated-desktop-profile` 后恢复网络，把命令状态、冲突提示和草稿是否保留的观察告诉我；能保存页面截图更好，但不是必需。我会运行只读事后核对，确认旧草稿未落盘、索引仍为空、测试凭据与 profile 不变、WH 已卸载。不要发送 `.work` 原始日志，里面可能包含本机临时访问令牌。
