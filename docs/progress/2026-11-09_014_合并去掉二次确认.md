# S05 / v1.0.0-rc.14：合并去掉二次确认（r201）

## 目标与范围

- 用户反馈（m03719）：点“合并这一组”之后又弹了一次确认框；按钮点击本身就是确认，不应再问第二遍。
- 范围只限合并入口的确认行为：单组“合并这一组”与批量“确认合并（N 组）”都改为点击即执行。
- 不做：合并前的预览/差异查看、撤销 UI 改动、批量选择逻辑改动。

## 实现

- `src/client/ManagementPage.tsx`：删除批量合并前的 `window.confirm(\`合并 ${mergePick.length} 组？…\`)`；删除单组合并前的 `window.confirm('合并这两条记录？…')`。按钮文案不变（“确认合并（N 组）”本身已是一次确认动作）。
- 合并结果行保留：无论成功/跳过/失败，组列表收起后仍显示“已合并 N 条来源；…”的 `role="status"` 提示。
- 来源仍标记为 `superseded`，账本保留最近 100 条，可在“最近自动合并（可撤销）”里撤销。
