## 2. 实现

### 2.1 自动标题（src/store.ts）

- 新增 `deriveTitle(description, name)`：取描述首句、压缩空白、最多 60 字符（超出加 `…`）；描述为空时把 name 的 `-`/`_` 换成空格。
- `writeInternal`：`title = record.title ?? existing?.title ?? deriveTitle(...)`；显式传入的 title 永远优先，内容未变时不会因为自动标题触发降级。
- `renderIndexBody`：标题与描述相同时改用 name 作为索引标签，避免“标题=描述”的重复展示。
- 用 `.work/repair-titles.mjs` 一次性补齐 4 条缺标题存量记录（保留原 status）。

### 2.2 质量提示内联（src/client/ManagementPage.tsx）

- 体检结果按 `name` 建 Map，每条记录标题行之后直接渲染该类提示（`aria-label="<name> 的质量提示"`）。
- 页面底部只保留汇总与“警告优先处理”的说明，不再逐条重复列出。

### 2.3 项目任务落点（0.6.0 行为，本次验证）

- 桥接创建宿主任务时，项目作用域任务带 `target.create.cwd`；user 作用域任务保持宿主默认（计划 B）。
- 验证任务 `project-task-landing-test`（project scope、cwd = 插件仓库、dueAt = 2026-11-07T15:36:33.843Z）。
