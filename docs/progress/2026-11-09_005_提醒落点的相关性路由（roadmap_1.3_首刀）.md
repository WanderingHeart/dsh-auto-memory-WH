# r192 — v1.0.0-rc.5 提醒落点的相关性路由（roadmap 1.3 首刀）

日期：2026-11-09
阶段：S05（v1.0 发布线）
上一版：v1.0.0-rc.4（同主题自动合并门槛 60%，r191）

## 1. 目标与范围

- 交接单下一项 **1.3 跨会话提醒**：把“提醒投到哪个会话”从固定策略改成按**提醒内容与本会话/已知项目的关系**决定。
- 首刀范围：`memory_remind` 创建时的落点路由 + 关闭/重开补投的插件侧覆盖。
- 明确不做：不自动新开会话、不静默改 target（每次改落点都带 `reason`）；低相关性强制询问暂缓——没有项目/主题证据时仍默认本会话，避免日常提醒被反复追问。

## 2. 实现

- 新增 `src/reminder-routing.ts`（纯函数）：
  - `decideReminderRoute({ text, sessionId?, currentCwd?, currentTopics?, requested, knownProjects?, archived? })` → `{ target: 'current' | 'new_once' | 'ask', cwd?, reason, question? }`。
  - 规则顺序：显式 `new` → `new_once`；无会话 → `new_once`；显式 `current` → `current`；归档 → `new_once`；提醒文字命中**另一个**已知项目（整串或 ≥2 个项目名 token）→ `new_once` + 该项目 `cwd`；同时命中本会话（项目名/主题词）与其他项目、或命中多个项目 → `ask`（不创建，返回问题）；否则 `current`。
  - 项目名与路径里的 `-`/`_` 按分隔符切 token，避免整串被当成一个词；通用词单个命中不算项目。
- `src/memory-tools.ts`：`memory_remind` 新增 `route: 'auto' | 'current' | 'new'`（`newSession` 保留为兼容别名）；`routeReminder` 选项返回 `ask` 时不创建提醒，工具返回 `{ needsConfirmation, route: 'ask', question, reason }`；输出 schema 相应放宽。
- `src/index.ts`：接线只读项目清单（`listProjects`）与当前 scope 主题标题（`readTopicRegistry`）；两者读取失败都退回“默认本会话”，不因路由失败丢提醒。
- `docs/configuration.md`：`memory_remind` 参数与询问行为。
- `docs/attachments/roadmap.md` 1.3：登记“关键词路由 + 歧义询问”已落地，以及 30 分钟宽限的补投窗口。
