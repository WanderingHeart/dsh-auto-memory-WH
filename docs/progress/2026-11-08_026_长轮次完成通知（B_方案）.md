# r177 — v0.11.0 长轮次完成通知（B 方案）

- 日期：2026-11-08
- 版本：0.11.0（切版、候选、隔离验收、桌面升级）
- 方案：B —— 检测到长时间运行结束，用小鲸鱼气泡提示“这一轮跑完了”

## 1. 动机

助手无法主动弹窗，长任务跑完后所有者只能盯着窗口。此前已有的通道是小鲸鱼
`window.__dshWhaleNotify`（v0.7.0 起用于到期提醒），这里复用它做“完成通知”：
只在单轮运行时间超过阈值时提示，短对话保持安静。

## 2. 实现

### 2.1 宿主跟踪（`src/completions.ts`）

- `CompletionTracker` 监听 `agent/status` 的 `running` / `idle` 变化，记录每个会话本轮起点。
- `running → idle` 且时长 ≥ `minDurationMs`（默认 60 秒）时生成完成事件
  `{ id, sessionId, startedAt, endedAt, durationMs }`；`id = sessionId@startedAt` 供客户端去重。
- 只保留最近 20 条（内存环形缓冲），宿主重启即清空。

### 2.2 只读接口（`completion.pending`）

`POST /api/auto-memory-wh/completion.pending` 返回：

```json
{ "enabled": true, "minSeconds": 60, "items": [{ "id": "…", "sessionId": "…", "durationMs": 90000 }] }
```

关闭 `notifyDone` 时返回 `enabled:false` 与空列表，客户端据此停止轮询。不读正文、不写记忆。

### 2.3 客户端（`src/client/completion-notify.ts`）

- 每 15 秒轮询一次；检测 `window.__dshWhaleNotify`，没有钩子时不注册定时器（宽限期 2 分钟后放弃）。
- 命中未提示的事件时调用 `__dshWhaleNotify({ lines:[{type:'text',text:'✅ 这一轮跑完了，用时约 N 分钟'}], ttlMs: 8000, sound: true })`。
- 已提示的 id 记在 `sessionStorage`（24 小时），刷新页面不重复弹。

### 2.4 配置

- `notifyDone: true`（默认开启）
- `notifyDoneMinSeconds: 60`（10–3600 整数）

## 4. 边界与未覆盖

- 只在 DSH 打开期间生效；桌面关闭时不会有完成通知。
- 完成事件只存在内存，宿主重启会丢；这是即时提示，不追求补发。
- 没装小鲸鱼时静默，不影响任何注入或宿主投递。
- 阈值按“单轮运行时长”计算，包含推理与工具执行；批量长任务结束时会只弹一次。
- 真实“长轮次”端到端体验需重启后观察（本轮验收只覆盖单测与隔离套件）。
