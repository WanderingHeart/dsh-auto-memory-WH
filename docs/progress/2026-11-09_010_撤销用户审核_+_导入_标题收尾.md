# r197 — v1.0.0-rc.10：撤销用户审核 + 导入/标题收尾

日期：2026-11-09
版本：1.0.0-rc.10
范围：Web 面板、注入策略、任务提醒、文档

## 1. 目标与范围

- 撤销“用户审核”这一强制步骤：记忆写入即参与注入，审核不再是使用前提。
- 清理所有“待审核 / 已审核 / 审核通过”文案（面板、用户指南、发布说明、架构/配置/质量文档）。
- 修复 JSON 包拖入无效内容（如只有 `111`）时无提示的问题。
- 总结浮层里路径型会话标题改为“未命名会话 · 项目名”。
- 补齐发布材料（`docs/attachments/release.md`）与用户指南。

不在范围：删除底层 `memory.review` API / `store.review`（保留兼容）；跨主题自动合并策略调整；归档历史改写。

## 2. 实现

### 注入与任务

- `src/injection.ts`：过滤条件改为只排除 `disabled`、`disputed`、`superseded`、`isStale`；candidate 与 legacy 均注入。`MEMORY_POLICY_TEXT` 与 `TASK_POLICY_TEXT` 明确“没有审核步骤”。
- `src/store.ts`：`MEMORY.md` 渲染同样纳入 candidate/legacy，仍排除任务、静音、有争议、已取代。
- `src/tasks.ts`：可提醒任务 = open 且非 disputed/superseded/停用。
- `src/memory-tools.ts`：`memory_write` / `memory_read` 描述与只读错误改为“自动注入”；`memory_write` 仍不接受 `type: task`。
- `src/export-agents.ts`：AGENTS.md 导出只排除 disputed/superseded。

### 面板

- 删除批量审核工具条、行内勾选框、“未审核”筛选按钮与 `batchReview`；`save()` 不再发送 `approve`。
- `statusLabels` 改为：自动记录 / 已确认 / 旧记录 / 有争议 / 已取代。
- 文案更新：合并说明段删除（用户点名）、确认合并、自动合并“会自动合并为一条记忆”、远端“另存为独立版本”、摘要“整理成记忆”“已写入，可在列表里查看。”、质量阈值“超过 180 天未更新”。
- 新增 `sessionLabel(row)`：标题为空、以 `@` 开头或盘符路径时显示“未命名会话 · 项目名（cwd 末段）”。
- `loadTransferFile`：先 `JSON.parse` 失败提示“不是有效的 JSON”，再校验 `records` 数组，失败提示“文件里没有 records 列表”，通过后才调 `import.plan`。

### 文档

- 新增 `docs/attachments/release.md`（rc.1–rc.10 汇总）。
- 重写 `docs/attachments/user-guide.md`：无审核语义、JSON 包/拖拽、人物弧光、`memory_reminders`、工具表、已知限制。
- 更新 `docs/attachments/architecture.md`、`docs/configuration.md`、`docs/attachments/memory-quality.md` 的审核描述。
