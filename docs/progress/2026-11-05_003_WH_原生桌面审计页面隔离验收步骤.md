# WH 原生桌面审计页面隔离验收步骤

日期：2026-11-05。对象：DSH Desktop `0.2.1-rc.5` nightly、WH `0.1.0-rc.8`，只使用项目 `.work/S05/native-real-user-home`。**原生页面操作已由用户执行，结果见[r73](2026-11-05_018_rc.8_原生桌面审计页面验收.md)。以下保留当时的步骤作复核记录，勿再次直接执行。** 本轮只读查看一条预置的合成组装审计；没有模型调用。

## 已核对的起点

- 在隔离目录内，用 DSH 的会话服务新建一条标有“WH 原生隔离审计合成会话 r72”的会话，工作区位于项目 `.work/S05/native-real-user-home/synthetic-audit-workspace`。原有空白会话先备份，写入后逐文件核对未变；会话种子没有模型调用。
- 用当前已安装的 WH rc.8 和 DSH 宿主组装服务，为该合成会话生成一条 `render_attempt`。项目记忆 `native-audit-reviewed-r72` 已审核并被选中；用户记忆 `native-ui-synthetic` 保持静音，在审计中被标为 `disabled`。这是**组装尝试**，不是模型已收到内容的证据。
- 原有三个隔离记忆文件已备份到 `.work/S05/native-audit-memory-baseline-r72/`。当前[只读预检](../attachments/public-validation.md)为 `pass=true`：新会话、审计、项目记忆有效；原有会话/记忆、五个 profile 文件和空白测试凭据均未变。正常桌面账户的安装前检查返回 `ready-for-isolated-desktop-reinstall`、DSH 进程 0。

## 用户离线操作

请使用**普通 PowerShell**，不要以管理员身份运行。先正常退出所有 DSH 窗口，再断开互联网。每一步不符合预期就停止；恢复网络后把情况告诉我。不要登录、填写 API Key、发送消息、选择真实模型或操作真实记忆。

1. 安装隔离 WH 包；看到 `installed-in-isolated-desktop-profile` 才继续：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Install -PostRemoveBaseline -OfflineConfirmed
   ```

2. 检查与启动；分别看到 `ready-for-isolated-wh-desktop-launch`、`isolated-wh-desktop-launched-not-yet-accepted`，再继续：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Check
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-wh-resume.ps1" -Action Launch -OfflineConfirmed
   ```

   若在欢迎页，仍按“添加 API Key → 稍后配置”进入工作区，不输入密钥。找到并打开**“WH 原生隔离审计合成会话 r72”**，会话 ID 开头是 `b0b0bd3d`；它与原有空白会话不同。如果看不到这条会话，或打开时要求登录、密钥或模型操作，停止页面验收，勿自行创建或发送新会话。

3. 在“记忆 WH”页面，先在“会话”下拉框选择上述合成会话，再把“范围”切换到**项目记忆**，点“查看组装审计”。预期看到“组装审计（不是模型成功接收凭据）”、字节数大于零、“已选：native-audit-reviewed-r72”。再将范围切换到**用户记忆**，保持同一会话，重新点“查看组装审计”；预期该次事件的“已选：无”，并在“未选”中看到 `native-ui-synthetic（已静音）`。不要编辑、审核、静音/取消静音或导出任何记录。

4. 正常退出 DSH，确认没有 `DeepSeek Harness` 进程，再卸载隔离插件：

   ```powershell
   & "C:\Users\example-user\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe" -NoProfile -File "C:\Users\example-user\Desktop\dsh-plug-in\dsh-auto-memory-WH\scripts\verification\native-desktop-plugin.ps1" -Action Remove -OfflineConfirmed
   ```

   看到 `removed-from-isolated-desktop-profile` 后恢复网络，告诉我四段命令状态、合成会话是否可见、项目/用户审计页面的观察结果；可选保存页面截图。不要发送 `.work` 原始日志，其中可能有本机临时访问令牌。我会运行只读事后核对，确认审计事件、记忆、原有会话、凭据和卸载状态。

如果第 2 或第 3 步无法继续，正常退出 DSH 并运行卸载命令后恢复网络；保留合成现场供诊断。此计划只验证**预置审计在原生页面的展示**，不会证明原生 UI 自己触发了组装、模型接收或完整出站隔离。v0.1.0 工作量估算仍约 **84%**，现场结果出来后再评估。
