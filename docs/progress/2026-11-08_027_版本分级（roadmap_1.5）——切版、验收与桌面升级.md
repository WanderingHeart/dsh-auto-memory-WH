# v0.12.0 版本分级（roadmap 1.5）——切版、验收与桌面升级

- 日期：2026-11-08
- 版本：`0.12.0`
- 候选包：`.work/dsh-auto-memory-wh-0.12.0.tgz`（172,397 字节）
- 环境：Node v24.22.0；隔离 `wh-s05`；日常 `desktop` 从 `0.11.0` 升级。

## 1. 背景

`roadmap.md` 1.5 要求“按 token 消耗与功能面提供三档”，约束是配置开关、不分叉存储、三档读同一份 `memory-wh`，且不改信任与审核语义。本轮把三档落到 `edition` 配置，作为 5.7 公开发布候选的前置交付。

## 2. 实现

### 2.1 档位与功能开关

`src/editions.ts`：

| 档位 | 索引预算建议 | 提醒 | 自动固化 | 自动备份 | 合并 | 关系图 | 导入导出/迁移 | 批量审核 |
|---|---|---|---|---|---|---|---|---|
| `minimal` | 2048 | 否 | 否 | 否 | 否 | 否 | 否 | 否 |
| `standard` | 4096 | 是 | 是 | 是 | 是 | 否 | 是 | 否 |
| `full`（默认） | 4096 | 是 | 是 | 是 | 是 | 是 | 是 | 是 |

- 三档共用同一份存储；档位只影响注入预算建议、可选功能与后台任务。
- `editionFeatures()` 每次返回新对象，调用方不能改到全局 profile。

### 2.2 宿主侧

- `Config.edition`（`minimal` / `standard` / `full`，默认 `full`）；`normalizeConfig` 拒绝未知档位。
- 自动固化按 `config.autoSummarize && features.autoSummarize` 生效；自动备份按 `config.autoBackup && features.autoBackup` 生效。
- 低功能档不注册 `memory_remind`（`enableRemind: false`），工具面回到“五工具”。
- `groups.list` 返回 `edition` 与 `features`，面板据此渲染。

### 2.3 API 门禁

未启用功能返回 `EDITION_DISABLED`（403）：

- `features.merge`：`memory.duplicates`、`memory.mergeSuggest`、`memory.merge`
- `features.graph`：`relatedness.graph`
- `features.importExport`：`export.package`、`import.plan`、`import.apply`、`export.markdown`
- `features.migration`：`migration.status`

### 2.4 面板

- 工具栏隐藏“重复与合并”“关系图”；设置菜单隐藏“立即备份”“导出 ×2”“迁移检查”。
- 批量审核复选框与批量操作按钮按 `features.batch` 隐藏。
- “存储”抽屉新增一行“功能档：低/中/全功能版（三档共用同一份存储，只影响注入预算与可选功能）”。

## 4. 边界与未做

- 没有多包/多构建产物：三档共用同一个 npm 包，仅靠配置切换；未做“按档发不同包”。
- 档位不改变存储格式、审核语义与同步协议；切档不需要迁移。
- 预算列只是建议值，实际仍由 `maxBytes` / `auditMaxBytes` 决定。
- 三档 × 干净环境的正式验收矩阵（5.7 要求）仍未做。
- 现有测试的 mock 不带 `features` 时按全功能渲染，避免旧测试因隐藏入口失败；真实宿主总会返回 `edition`/`features`。
