## 5. 踩坑与修正

- `compat-matrix` 最初复用 `installed-peer-topology.cjs` 的 `peers check` 走隔离 CLI，`dsh plugin --profile wh-s05 peers check` 退出 1 且 `pnpm.log` 无诊断；改为直接以 Electron Node 运行 `installed-peer-topology.cjs`（stage 必须匹配 `S05-<version>-host-deps`），通过。
- compat 的极简 semver 比较器不支持 `^` 与 `||`，补上后才通过 Node 范围。
- 干净环境演练里 Node 24 对 `.cmd` 直接 `spawnSync` 报 `EINVAL`，改用 `powershell.exe -NoProfile -Command` 取 DSH 版本（版本号在 stderr）。
- `THIRD_PARTY_NOTICES.md` 此前停在 2026-11-04、0.7.x 口径；已按当前 lockfile 重生成并标注 47 条无 license 字段与 55 条无许可文件，未做漏洞审计。

## 6. 边界

- 只有一件 DSH 版本可用（`0.2.2-rc.1`）；第二套版本矩阵未执行，需另一台装不同 DSH 的机器。
- `npm publish`、GitHub Release、文档站托管、`.git` 操作均未做（需所有者账号/权限）。
- 47 条无 license 字段的包（以 `@rolldown/binding-*` 平台二进制为主）未逐条补许可文本；发布前需人工复核或剔除。
- 干净环境演练使用合成记忆与本地 tgz，不涉及真实账号与远程服务。
