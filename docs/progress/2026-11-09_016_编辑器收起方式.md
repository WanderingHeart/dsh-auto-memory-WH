# r203 — v1.0.0-rc.16 编辑器收起方式

## 目标与范围

- 编辑一条记忆时，“查看 / 编辑”按钮改为“查看 / 编辑：取消”，点击即可收起编辑器。
- 点击卡片空白处或列表卡片之间的空白，也收起当前编辑器。
- 不改保存逻辑、不改数据格式。

## 实现

- `src/client/ManagementPage.tsx`：行内按钮在该行处于编辑态时显示“查看 / 编辑：取消”，点击调用 `setDraft(null)`；其他行处于编辑态时按钮保持禁用。
- 卡片内容容器与 `.dam-wh-groups` 增加点击处理：仅当 `event.target === event.currentTarget`（点在容器自身空白处）时收起，避免点到文字/按钮误关。
- 测试：新增“closes the editor from the row toggle or by clicking the surrounding whitespace”，覆盖按钮取消、卡片空白、列表空白三条路径。
