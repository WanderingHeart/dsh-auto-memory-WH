# S05 / v1.0.0-rc.8 — 提醒时间的本地时区视图（r195）

## 目标与范围

用户发现宿主 `schedule_list` 的 `scheduledAtLocal` 按 `+00:00`（UTC）显示，要求“改成按本地时区显示，最好按每个用户机器时区”。

排查结论：`scheduledAtLocal` 不在本插件源码中，由宿主 `schedule_list` 工具格式化；本机 DSH 安装是 `app.asar` 运行态，磁盘上没有可读的宿主源码，因此**不改宿主**。本版在插件侧提供等价的本地时间视图，不改提醒本身、不改宿主调度器。

## 实现

- 新只读工具 `memory_reminders`（全功能档，随 `reminders` 开关）：列出本插件创建的提醒，返回
  `{ timeZone, reminders: [{ id, title, scheduledAt, localTime, active, status }] }`。
  - `timeZone` 取 `Intl.DateTimeFormat().resolvedOptions().timeZone`，即用户机器时区。
  - `localTime` 由 `new Date(scheduledAt).toLocaleString(undefined, { timeZone })` 生成；解析失败时原样返回。
  - 标题去掉 `记忆提醒：` 前缀；按 `scheduledAt` 升序；宿主没有 `schedule` 服务时返回 `REMINDER_UNAVAILABLE`。
- `src/index.ts` 把宿主 `schedule.list({ limit: 200 })` 收成 `listReminders` 注入工具层；工具本身不写、不删、不改 target。
- `docs/configuration.md` 任务提醒一节补充 `memory_reminders` 与“宿主 `schedule_list` 可能显示 UTC，以本工具为准”的说明。

## 未测边界

- 不改宿主 `schedule_list`：它仍按自己的格式显示；要看本地时间请用 `memory_reminders`。
- `memory_remind` 的结构化 `timing` 仍是 UTC ISO 或 `after_seconds`；本地展示由 `memory_reminders` 承担。
- 本地时间依赖 Node 的 ICU 与操作系统时区；夏令时/跨日期的显示未单独构造用例，按 `toLocaleString` 的标准行为处理。
