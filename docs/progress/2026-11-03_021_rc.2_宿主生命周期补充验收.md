# S05 rc.2 宿主生命周期补充验收（r16）

日期：2026-11-03。状态：**partial**。本轮仅新增隔离宿主探针和证据；插件生产代码、rc.2 候选包、日常 DSH 配置均未改动。

## 方法与结果

用本机打包的 DSH Cordis、SystemPrompt、Tools、Loader 和已安装于 `wh-s05` 隔离配置的 **0.1.0-rc.2** bundle，在项目 `.work/S05` 下创建全新合成数据根。运行时 Electron 44.7.0；探针记录了已安装 bundle 的 SHA-256，以区分工作树与安装产物。[完整结果](../attachments/public-validation.md)。

通过五项检查：

1. 合成父会话和子会话并行组装时，共享已审核的用户记忆，但各自只读到自身项目记忆；异项目内容未串入。
2. 已取消信号的组装在已安装 rc.2 bundle 中返回空记忆段。
3. 发出合成会话关闭事件、卸载再加载插件后，五工具与记忆段没有重复注册；新合成会话仍能读取已审核的持久记录。
4. 宿主 `complete` section 在 waterfall 后保持独占最终系统提示词。
5. 插件关闭并排空审计队列后，取消组装持久记录为 `render_attempt`、`assembly-aborted`、0 字节。

首次审计检查在组装返回后立即读取文件，早于异步审计落盘，出现假失败；改为在关闭并排空队列后检查，同一合成数据的审计文件可见正确记录。最终探针退出码 0。类型检查、构建、完整回归 **268/268** 通过：[类型检查](../attachments/public-validation.md)、[构建](../attachments/public-validation.md)、[测试结果](../attachments/public-validation.md)。

## G4 边界

这些 agent/session 对象和事件是**合成的**。测试验证了实际安装包与宿主服务在这些输入下的范围和生命周期行为，没有启动真实子代理、真实压缩/恢复流程或模型请求；也没有验证取消发生在实际模型调用期间的宿主调度。`complete` 覆盖后仍可能有非零的组装尝试审计，不能解释为模型已收到记忆。T18 的可模拟部分得到证据，完整 T18/G4 继续开放。

日常 DSH、真实记忆和模型密钥未使用；没有安装新包、迁移真实数据或发布。下一步应针对真正的会话压缩/子代理 API 寻找可在隔离环境执行的无模型路径，并记录无法验证部分的条件。
