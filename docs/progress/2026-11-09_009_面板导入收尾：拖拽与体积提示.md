# S05 / v1.0.0-rc.9 — 面板导入收尾：拖拽与体积提示（r196）

## 目标与范围

1.2 的第三刀，收掉 rc.7 面板 JSON 包导入留下的两处易用性缺口：

- 导入只支持“设置菜单 → 选择文件”，不能直接把包拖进面板；
- 预演只显示校验和与新增/更新/冲突计数，不显示包体积与记录数，超大文件也会先完整读进内存再报错。

本版只改面板交互与提示，不改导出/导入协议、不改冲突语义（仍为“保留本地 / 两边都留”）、不引入导入历史或自动合并。

## 实现

- `src/client/ManagementPage.tsx`
  - 面板根节点接受 `dragover` / `dragleave` / `drop`：拖入文件时显示虚线遮罩“松开以预演导入 JSON 包”，松开后复用同一套 `loadTransferFile` 流程（预演 → 用户选策略 → 应用）。
  - 预览头部改为“文件 12.3 KB · 21 条记录 · 校验和 xxxxxxxx · 新增 a · 更新 b · 相同 c · 冲突 d”。
  - 单文件上限 2 MB（`MAX_TRANSFER_BYTES`）：超过直接提示“请拆分包后再导入”，不解析、不调用 `import.plan`。
  - 记录数从包内 `records` 数组取，导出包结构与 `wh-memory-export` v1 一致；旧包没有 `records` 时显示 0 条记录，不影响预演。
- `src/client/index.ts`：新增 `.dam-wh-dropzone` 遮罩样式（固定覆盖、虚线边框、`pointer-events:none`）。
- 已有入口保持不变：设置菜单里的“导出 JSON 包 / 导入 JSON 包”和隐藏文件输入仍可用。

## 未测边界

- 拖拽只处理单个文件；多文件拖入时取第一个，其余忽略。
- 冲突行仍只列记录名，不展示本地/远端的标题或摘要差异；“为什么冲突”需要打开记录自行比对。
- 2 MB 是面板侧上限，不是协议上限；CLI/API 路径不受此限制。
- 旧版导出包（无 `records` 字段）在预览里显示 0 条记录，但服务端仍按实际内容预演。
- 升级时 DSH 仍在运行，内存里仍是 rc.8；需要完全退出重开才会加载 rc.9 的客户端 bundle。
