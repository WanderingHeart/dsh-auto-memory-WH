## 3. 代码及验收方式

本轮没有修改插件生产逻辑或重新安装。新增已安装包的宿主事件探针，并给 React 管理页增加“旧会话撤销、新会话出现”的交互测试。探针须以桌面端 Electron 的 Node 模式运行，才能读取打包 `app.asar` 中的实际宿主服务；请求仅在 `127.0.0.1`，临时凭据仅存于进程内，证据不包含登录 token。

前后例子：合成会话 `synthetic-old-session` 关闭前是可管理目标；关闭后，旧 ID 消失且项目接口拒绝它；`synthetic-new-session` 创建后成为唯一可选目标。页面不再把历史会话目录本身当作授权。
