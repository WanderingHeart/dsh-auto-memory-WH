# r170 · v0.8.8 设置菜单常驻与功能面板并列悬浮

日期：2026-11-08
目标版本：v0.8.8（在 v0.8.7 基础上）

## 1. 用户意见

> 位置对了，但是不是我想实现的那种样子，我点开一个之后，整个这个设置界面是要保留的，同时要有我点开的内容对应的部分悬浮在边上，像这张图片里的这样的效果

即：点击设置项后，设置菜单不收起；对应功能面板作为独立浮层出现在菜单左侧，两者并列（类似右键菜单弹出子菜单）。

## 2. 改动

- `src/client/ManagementPage.tsx`
  - `openPanel()` 不再调用 `settingsRef.current?.removeAttribute('open')`，菜单保持展开。
  - 新增 `drawerRight` 状态：读取设置菜单实际宽度，设为 `菜单宽度 + 62px`（窄于 760px 时退回 `0`，走整宽媒体查询），面板以 `style={{ right: drawerRight }}` 悬浮在菜单左侧。
  - 点空白处的处理改为“菜单与面板都不包含点击目标才关闭”，点菜单或面板内部均保持打开；Esc 关闭两者。
- `src/client/index.ts`：`@keyframes dam-wh-drawer-in` 从纵向位移改为 `translateX(8px)`，从菜单一侧滑入。

## 4. 行为说明

- 点设置菜单中的任意项：菜单保留，面板从菜单左侧滑出；再点另一项只替换面板内容。
- 点菜单或面板之外：两者同时关闭；按 Esc：两者同时关闭；面板右上角 × 仍可单独关闭面板。
- 窄窗口（<760px）上面板整宽显示，菜单在面板下方仍可点。
