# r194 — v1.0.0-rc.7：面板 JSON 包导入 / 导出与冲突预览

日期：2026-11-09
阶段：S05（1.2 三端导入导出与冲突合并，第二刀）

## 目标与范围

- 面板补齐 `wh-memory-export` JSON 包的导出与导入入口，不再只能走 API / CLI。
- 导入必须先只读预演：显示新增 / 更新 / 相同 / 冲突数量与冲突记录名，再由用户决定冲突策略。
- 冲突策略只有两种，都保证不丢一端：**保留本地（跳过远端）** 或 **两边都留（远端存为待审核候选）**。
- 不做：拖拽上传、导入历史、跨设备自动同步、自动合并导入结果。

## 实现

- `src/client/ManagementPage.tsx`
  - 设置菜单新增「导出 JSON 包」（`export.package`，下载 `<scope>-package.json`）与「导入 JSON 包」（隐藏 `<input type="file">`）。
  - 选中文件后读取文本、`JSON.parse`，调用 `import.plan` 得到只读预演；新增 `ImportPlanView` 状态与「导入预览」区块。
  - 冲突时展示冲突记录名与两个单选：保留本地 / 两边都留；「应用导入」调用 `import.apply`，带 `approvedChecksum` 与 `onConflict: 'skip' | 'fork'`。
  - 完成后提示新增 / 更新 / 跳过 / 保留双方数量，并刷新列表。
- `src/client/index.ts`：新增 `.dam-wh-transfer*`、`.dam-wh-hidden-file` 样式，沿用 `--dsw-alias-*` 变量。
- 服务端未改：复用 rc.6 已落地的 `export.package` / `import.plan` / `import.apply` 与 `onConflict: 'fork'`。

## 未测边界

- 导入大文件只有服务端 32KB / 记录数上限兜底，面板没有提前提示体积。
- 面板只做单文件导入；没有拖拽、没有导入历史、没有“先导出再导入”的往返演练。
- 冲突预览只按名字列出；用户看不到远端与本地内容差异（需先手动打开记录比对）。
- fork 后的副本仍需人工审核；旧客户端忽略 `topic` 与 `fork` 的兼容性未在第二台设备上实测。
