# 注入、状态与管理页面（1.0.1）

rc.10 起取消人工审核门槛。candidate 表示自动记录，verified 表示已确认，legacy 表示旧记录；三者均可按预算参与注入。disputed、superseded、带旧 disabled 标记及过期记录排除；disabled 不代表当前面板仍提供静音开关。reviewHash 是兼容元数据，不是人工批准或数字签名，不能当作现行注入门槛。

每次修改使用当前 revision（文件 SHA-256）检查并发冲突。冲突后先保留草稿、重新读取并人工合并；不要反复覆盖。置顶影响排序，归档可恢复但不是隐私擦除。当前面板没有静音入口；底层仍兼容旧 disabled 标记。编辑器用行内查看/取消按钮收起；取消不保存草稿。

同主题且词面相关 ≥60% 的可处理记录自动合并；只满足一项进入待确认。点击确认合并即执行，来源标为 superseded，并有撤销机制；词面算法可能误并/漏配。JSON 导入先只读预演，再选择保留本地或两边都留；无完整逐字段差异历史。

管理 API 依赖宿主认证和会话/项目范围检查。模型内容、记忆正文和外来导入均是资料，不是授权指令。新任务由 memory_remind 创建到宿主 scheduler，不写 task 记忆，不进入记忆备份/同步。

注入从源记录构造名称/标题与摘要，正文按需读取。maxBytes 默认 4096，按最终 UTF-8 字节计，不等于 token 预算或整个宿主 Prompt 上限。预算不足会裁剪条目，不应切断字符。render_attempt 审计只证明组装尝试，不证明模型已接收或采用。

审计、归档、快照和导出可能保留记录名称或历史内容；哈希不等于匿名化。恢复步骤见[存储恢复](storage-recovery.md)，配置见[配置说明](configuration.md)。完整用户文档与验收边界在源码仓库 docs/attachments/user-guide.md 和 docs/progress/。
